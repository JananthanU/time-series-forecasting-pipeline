# Bachelor-Thesis-ML-pipeline

Public demo of my bachelor thesis ML workflow.

## Data disclaimer
The dataset included in this repository is **not real**. It is a synthetic / dummy dataset provided only to demonstrate the pipeline and ensure the project can run end-to-end.

Because the data is not real, the outputs (metrics and forecasts) are not representative. Example plots generated from the dummy data are stored under `reports/figures`. To obtain realistic results, you must replace the input data with a real dataset in the same format (or adjust the preprocessing accordingly).

## Goal
The goal of this project was to forecast the total number of closures for the next month using a time-series forecasting workflow with feature engineering, model selection, and evaluation.
